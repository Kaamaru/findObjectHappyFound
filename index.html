API Documentation

POST /newpost

Creates a new "found item" post. This is a multipart form submission.

Fields:

  • image_file_bytes: The image file of the found item.
  • finder_name: (Text) The name of the person who found the item.
  • found_location: (Text) Where the item was found.
  • contact: (Text) Contact information for the finder.

Returns:

A status code and a string indicating the result of the upload and post creation.

POST /upload

Uploads one or more files. This is a multipart form submission.

Details:

The 'name' of each form field will be used as the file name in the storage bucket.

Returns:

A status code and a string with the upload results for each file.

PUT /hello

A simple test endpoint.

Request Body (JSON):

{"happy": boolean}

Returns:

The string "Hello World".

GET /form

An endpoint that takes query parameters.

Query Parameters:

  • data_size: (integer, required) A value between 1 and 10.
  • data_happiness: (integer, required) A value greater than or equal to 2.
  • optional_field: (string, optional) An optional text field.

Example:

/form?data_size=5&data_happiness=3&optional_field=test

Returns:

The string "Ok."

GET /ping

A simple health-check endpoint.

Returns:

The string "pong!".

GET /html

Returns:
